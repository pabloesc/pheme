# assets/

Place your Pheme logo here:

    assets/pheme-logo.png

Requirements:
- PNG format with transparency, or black on white background
- Recommended size: 200×200 px or larger (it will be resized to 128×128)
- Black lines on white — mailer.py auto-inverts to white-on-transparent for the dark header

If the file is missing, the header renders without a logo (graceful fallback).
